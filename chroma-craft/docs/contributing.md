# Contributing to Chroma-Craft

Thank you for your interest in contributing to Chroma-Craft!

## Guidelines
1. **Preserve Color Roster Integrity:** Changes to the 52 canonical colors must preserve mathematical contrast calibration and adhere strictly to the 7 allowed blues.
2. **WCAG Compliance:** All suggested pairings and recipes must meet or exceed WCAG 2.1 AA contrast thresholds ($\ge 4.5:1$ for normal text, $\ge 3:1$ for large text).
3. **Run Test Suite:** Run `python skill/scripts/test-chroma-craft.py` to ensure all tests pass before submitting changes.
