# Example 02: Corporate & Enterprise B2B SaaS Palette

> **Domain Archetype:** Enterprise Software, Financial Governance, B2B Cloud Tools  
> **Key Objective:** Authority, trustworthiness, institutional stability, zero visual noise.

---

## Aesthetic Rationale

Corporate stakeholders demand sobriety and visual dignity:
1. **Calm Structural Surfaces:** Viewport canvas uses **Snow White (`#FBFBFD`)**, while cards and content wells use **Pearl White (`#F8F6F0`)** for subtle spatial relief.
2. **Authoritative Blue Primaries:** Primary brand anchors use **Steel Blue (`#4682B4`)** and **Ocean Blue (`#0077BE`)**. Deep dark anchors use **Midnight Blue (`#191970`)**.
3. **No Flamboyant Neon:** Absolutely no fluorescent greens, vibrant pinks, or animated rainbow borders. Contrast remains strictly $>4.5:1$ across all data tables and dashboards.
4. **Contrast Verification:**
   - Text on Canvas: `#121214` on `#FBFBFD` = **18.10:1** (WCAG AAA)
   - Primary CTA Text: `#FBFBFD` on `#0077BE` = **4.64:1** (WCAG AA)
