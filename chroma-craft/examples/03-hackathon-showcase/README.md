# Example 03: Hackathon Showcase & AI Launch Palette

> **Domain Archetype:** Hackathons, AI Product Demos, Web3 Developer Launches  
> **Key Objective:** High-voltage energy, memorable visual impact for judges, futuristic dark canvas.

---

## Aesthetic Rationale

Hackathons require websites that capture attention within the first 5 seconds:
1. **Obsidian Dark Canvas:** The canvas is grounded in **Charcoal Onyx (`#121214`)**, avoiding muddy grey midtones.
2. **Radiant Electric Accents:** Interactive buttons and focus halos leverage **Electric Blue (`#0066FF`)** and **Cyan (`#00E5FF`)**.
3. **Cyber Nebula Hero Gradient:** Uses `linear-gradient(135deg, #121214 0%, #191970 50%, #0066FF 100%)` for dramatic atmospheric depth.
4. **Primary CTA Button:** `linear-gradient(135deg, #0066FF 0%, #00E5FF 100%)` with bold dark text (`#121214`), achieving **12.16:1** contrast.
5. **Contrast Verification:**
   - Body Text on Void: `#FBFBFD` on `#121214` = **18.10:1** (WCAG AAA)
   - Secondary Copy: `#C0C0C8` on `#121214` = **10.35:1** (WCAG AAA)
