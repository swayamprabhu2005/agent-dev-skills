# Example 04: Personal Portfolio & Creative Developer

> **Domain Archetype:** Creative Engineering Portfolio, Design Studio, Independent Consultant  
> **Key Objective:** Distinctive personal brand, editorial craft, typography focus, memorable signature accent.

---

## Aesthetic Rationale

Personal portfolios thrive on restraint, craft, and distinctive accents:
1. **The Signature Duo:** Built around a single memorable signature color — **Terracotta (`#E07A5F`)** — paired with a warm editorial canvas of **Ivory White (`#FFFFF0`)**.
2. **Editorial Typography:** Deep **Charcoal Onyx (`#121214`)** headlines and crisp borders allow work case studies and project screenshots to stand out.
3. **Contrast Verification:**
   - Body Text: `#121214` on `#FFFFF0` = **18.54:1** (WCAG AAA)
   - Accent on Dark Inversion: `#E07A5F` on `#121214` = **7.20:1** (WCAG AAA)

---

## File Contents
- `tokens.css`: Editorial CSS variables with signature terracotta highlights.
- `palette.json`: Portfolio design tokens.
