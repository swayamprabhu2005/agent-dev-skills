> **Mathematical Contrast Calibration & Color Vision Compliance.**

## 1. The WCAG 2.1 Standards Reference

The W3C defines contrast thresholds based on human visual acuity:

| UI Element Type | Definition | Level AA (Minimum) | Level AAA (Enhanced) |
| :--- | :--- | :---: | :---: |
| **Normal Body Text** | Font size $< 18\text{pt}$ ($24\text{px}$) or $< 14\text{pt}$ bold ($18.66\text{px}$) | **$\ge 4.5 : 1$** | **$\ge 7.0 : 1$** |
| **Large Text / Headings** | Font size $\ge 18\text{pt}$ ($24\text{px}$) or $\ge 14\text{pt}$ bold ($18.66\text{px}$) | **$\ge 3.0 : 1$** | **$\ge 4.5 : 1$** |
| **UI Components & Icons** | Input borders, active tabs, toggle switches, standalone icons | **$\ge 3.0 : 1$** | — |

## 2. Relative Luminance & Contrast Formula

The contrast ratio $CR$ between two colors with relative luminances $L_1$ and $L_2$ ($L_1 > L_2$) is:

$$CR = \frac{L_1 + 0.05}{L_2 + 0.05}$$

Where relative luminance $L$ is calculated from linear sRGB values:

$$L = 0.2126 \cdot R_{\text{linear}} + 0.7152 \cdot G_{\text{linear}} + 0.0722 \cdot B_{\text{linear}}$$

And each 8-bit sRGB channel $C \in \{R, G, B\}$ is linearized via:

$$C_{\text{linear}} = \begin{cases} \frac{C_{\text{sRGB}}}{12.92} & \text{if } C_{\text{sRGB}} \le 0.04045 \\ \left(\frac{C_{\text{sRGB}} + 0.055}{1.055}\right)^{2.4} & \text{if } C_{\text{sRGB}} > 0.04045 \end{cases}$$

## 4. Common Accessibility Anti-Patterns to Avoid

> [!CAUTION]
> The following combinations are common frontend design mistakes that violate accessibility standards:

1. ❌ **White Text on Cyan (`#00E5FF`):** Ratio is only **$1.49:1$** (Extreme failure).  
   *Correction:* Always use **`#121214` Charcoal Onyx** text on Cyan buttons ($12.16:1$).
2. ❌ **White Text on Lime (`#00FF00`):** Ratio is only **$1.33:1$** (Unreadable glare).  
   *Correction:* Use Lime strictly as a status dot or with deep dark typography.
3. ❌ **Silver Text on Snow White:** Ratio is only **$1.75:1$**.  
   *Correction:* Use Silver strictly for 1px borders or non-text dividers. For secondary text, use **Grey (`#6B7280`)** ($4.68:1$).
4. ❌ **Electric Blue Text on Charcoal Onyx for Small Body Copy:** Ratio is **$3.87:1$**.  
   *Correction:* Electric Blue on dark surfaces passes AA for Large Text / Headings ($\ge 3:1$), but for body text ($< 18\text{pt}$), use **Arctic Blue (`#C6E2FF`)** ($14.0:1$) or **Snow White** ($18.1:1$).

## 5. Color Vision Deficiency (CVD) Best Practices

Approximately 8% of men and 0.5% of women experience Color Vision Deficiency (Red-Green Deuteranopia / Protanopia, or Blue-Yellow Tritanopia).

### Chroma-Craft CVD Safeguards:
- **Never rely on color alone for critical status:** Pair color changes with icons (e.g. checkmark icon for success, exclamation mark for errors).
- **Distinguish alerts by luminance, not just hue:** For example, pair a light background tint with high-contrast dark text and an icon, rather than placing red text on green.
- **Form Validation Fields:** When an input has an error, do not merely turn the border red; add a prominent error icon, an explicit error string below the input, and an `aria-invalid="true"` attribute.
