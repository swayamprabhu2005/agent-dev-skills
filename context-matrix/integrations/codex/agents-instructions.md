## Prompt Architecture & Framework Guidelines
When formulating technical prompts, system designs, code reviews, or prompt evaluations:
1. Select the appropriate framework among the 8 Context Matrix frameworks:
   - **CLARITY:** Functional implementation and coding contracts.
   - **SOCRATES:** Architecture planning, resource trade-offs, and roadmaps.
   - **ANTICIPATE:** Tutorials, onboarding, and pedagogical guides.
   - **PARTNER:** Tool evaluations, empirical benchmarks, and PoC tests.
   - **TRUST:** Tailored recommendations and situational advisory.
   - **RIPPLE:** Systematic code reviews, root-cause debugging, and dataset audits.
   - **CATCH:** Rapid everyday requests, release notes, and concise scripts.
   - **MAGIC:** Creative content, comic scripts, and narrative deliverables.
2. Ground all prompts in verified repository context. Never fabricate files or citations.
3. For full methodology, reference `.agents/skills/context-matrix/SKILL.md`.
