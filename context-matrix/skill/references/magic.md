# MAGIC Framework

> **Purpose:** Turn open-ended creative ideas into well-defined, structured deliverables for storytelling, visual concepts, comic scripts, marketing campaigns, and multimedia production.

The **MAGIC** framework provides creative direction with engineering discipline. While creative generation thrives on imagination, without clear structural constraints, AI outputs drift into generic, clichéd tropes. MAGIC establishes creative intent, character/visual continuity, and concrete output specifications.

---

## 1. The 5 Components of MAGIC

```text
┌────────────────────────────────────────────────────────────────────────┐
│ M — Motivation : The creative inspiration, narrative theme, or hook    │
│ A — Audience   : The target viewers, demographic, or community persona │
│ G — Goal       : Desired emotional resonance, message, or outcome      │
│ I — Input      : Characters, world-building rules, style references    │
│ C — Create     : Exact deliverable format (script, storyboard, copy)   │
└────────────────────────────────────────────────────────────────────────┘
```

### Component Breakdown

1. **M — Motivation:**
   * What is the core narrative spark or creative premise? (e.g. "A humorous sci-fi story about a sentient compiler that refuses to compile unoptimized code").
2. **A — Audience:**
   * Who is this for? (e.g., DevOps engineers, young adults, enterprise B2B buyers). Adjust humor, vocabulary, and cultural references accordingly.
3. **G — Goal:**
   * What impact should the piece achieve? (e.g. "Inspire engineers to write cleaner tests while entertaining them with relatable humor").
4. **I — Input:**
   * Creative assets & constraints:
     * Character sheets (names, personalities, distinct voices).
     * Visual style constraints (e.g., "Cyberpunk anime aesthetic, neon cyan and magenta palette").
     * Continuity rules (preventing character traits from changing between panels).
5. **C — Create:**
   * Exact structure of the requested deliverable:
     * 4-panel comic script (Panel description, camera angle, character dialogue, sound effects).
     * 60-second video script (Visual cue, Voiceover audio, on-screen text).
     * High-converting product landing page hero section.

---

## 2. Visual & Narrative Continuity Discipline

> [!NOTE]
> **Creative Generative Disclaimer:**
> A well-structured prompt provides clear creative direction and consistent character descriptions, but does not guarantee identical pixel-level outputs across image-generation models. Where visual continuity matters, specify distinct signature features (e.g. "Always wears circular brass goggles, bright yellow safety jacket, and carrying an oversized wrench").

---

## 3. When to Use MAGIC

* **Primary Use Cases:**
  * Technical comics, educational cartoons, and storyboards.
  * Creative product copywriting, taglines, and marketing campaigns.
  * Video scripts, podcast outlines, and audio narration.
  * Worldbuilding, lore generation, and character design.
* **When NOT to Use:**
  * Functional code implementation or system architecture (use **CLARITY** or **SOCRATES**).
  * Direct bug fixes or code audits (use **RIPPLE**).

---

## 4. Evaluation Checklist for MAGIC Prompts

* [ ] Is the core creative motivation/theme distinct and engaging?
* [ ] Is the audience's tone and sensibility respected?
* [ ] Are character voices and visual constraints clearly detailed for continuity?
* [ ] Is the output deliverable structured with specific panel, scene, or section markers?
* [ ] Does the prompt avoid clichéd tropes by defining explicit creative guardrails?

## 5. Practical Example

### Example: Educational 4-Panel Comic Script (Git Merge Conflicts)

```markdown
**Motivation:** Demystify the panic junior developers experience when encountering their first Git merge conflict, showing that conflicts are just simple choices between two versions.
**Audience:** Junior web development students and bootcamp learners.
**Goal:** Relieve anxiety around merge conflicts through warm, relatable tech humor.
**Input:**
- Protagonist: Maya (eager junior dev, red hoodie, cat-ear headphones).
- Mentor: DevBot (small floating cube robot with an LED screen displaying emoticons).
- Visual Style: Clean webcomic style, 4 horizontal panels.
**Create:**
A 4-panel comic script specifying:
1. Panel visual layout and character expressions.
2. Dialogue and SFX.
3. Color mood per panel.
4. Concluding educational takeaway in the final panel.
```
