## Pre-Implementation Blueprint Gate
Before writing application code for any substantial new project or major feature:
1. Do not begin coding immediately. Ask 1-2 clarifying questions to resolve architectural ambiguity.
2. Generate the 5 Project Blueprint documents: PRD.md, TRD.md, UI_UX.md, BACKEND_SCHEMA.md, and APP_FLOW.md.
3. Validate cross-document consistency and ensure all requirements (REQ-xxx) are traceable.
4. Block implementation until the user explicitly issues approval ("Approved", "Proceed to implementation"). Casual remarks like "looks good" do NOT unlock coding.
